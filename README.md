## RULES FOR THIS REPO

1. Prefer **entire curated repositories** over adding isolated portfolio links.
2. Add single websites only when they are unusually useful and not already covered by a mother-library.
3. Keep sources separated into:
   - real portfolio collections
   - complete website skeletons/templates
   - experimental / interaction-heavy personal sites
   - newest 2026 discoveries
4. Always preserve the original repository URL.
5. Before copying code, check the original license. Public source does not automatically mean unrestricted reuse.
6. If a source repository has its own live demo/gallery, save that link next to the repo.

## PURPOSE

This is not a generic UI/UX component warehouse. It exists for one job only: **building and refining a personal portfolio website that can actually show the work.**
